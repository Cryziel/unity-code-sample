# unity-code-sample
An example of my Unity C# coding style
Written by me, no code generation or AI tools

Boat.cs - Code for a boat that the player (first-person controller) can board and move across water. The boat follows specific routes that switch when the player meets certain conditions.

GiantView.cs - The giant watch the player using a raycast. If there are no obstacles between the player and the giant, the giant can see and attack the player.
